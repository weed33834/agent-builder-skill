# Agent 管理控制台设计规格（Admin Console Design Spec）

> **背景**：Agent 平台不能只有聊天界面——每一个功能资产（提示词/工具/模型/记忆/Agent/评估…）
> 都需要**管理界面**：可视化管理、控制、布局，且支持 **AI 自动生成** 与 **外部导入**。
> 本文档定义统一管理界面模式（下文称"控制台"），并逐个模块给出深度设计。
> 对应 feature-checklist M8（前端 UI）扩展：新增 M8.16-M8.20 管理界面能力项。

---

## 〇、总体设计原则

1. **资源化**：一切可管理的东西都是"资源"（Prompt / Tool / Model / Agent / Memory / Dataset / Rule…）
   每个资源拥有统一生命周期：`创建 → 配置 → 测试 → 启用 → 监控 → 版本 → 停用/删除`
2. **统一操作面板**：每个资源详情页都由 4 个 Tab 组成：**配置 / 测试 / 运行 / 审计**
3. **三种输入通道**：人工编辑、AI 生成、外部导入——三者互为补充，且结果都进同一版本体系
4. **可测试优先**：任何资源保存前必须能"试跑"，测试不通过不允许启用
5. **权限分层**：查看 / 编辑 / 测试 / 启用 / 删除 五级权限，按角色控制
6. **热加载优先**：配置修改默认热生效（动态注册），需重启的显式标注

### 统一布局（控制台骨架）

```
┌─────────┬──────────────────────────────────────────────────────┐
│ 左侧导航  │  资源列表区               │  详情工作区（4 Tab）          │
│ ┌─────┐ │  ┌─────────────────────┐ │  ┌────────────────────────┐ │
│ │仪表盘│ │  │ 搜索栏 [筛选▾] [新建] │ │  │ [配置] [测试] [运行] [审计]│ │
│ │提示词│ │  │ 名称     状态  版本  │ │  │  配置表单/编辑器          │ │
│ │工具  │ │  │ prompt_a  ✅  v3   │ │  │  + [AI 生成▾] [导入▾]    │ │
│ │模型  │ │  │ prompt_b  🔶  v1   │ │  │  实时校验错误提示          │ │
│ │Agent │ │  │ ...                │ │  └────────────────────────┘ │
│ │记忆  │ │  └─────────────────────┘ │                            │
│ │编排  │ │   分页 | 排序 | 标签       │  ┌────────────────────────┐ │
│ │评估  │ │                          │  │ 版本历史 v3←v2←v1  [回滚]│ │
│ │监控  │ │                          │  └────────────────────────┘ │
│ │用户  │ └──────────────────────────┴────────────────────────────┘
└─────────┘
  右侧可折叠：AI 助手浮动面板 / 导入导出对话框
```

### 统一组件（每个模块复用）

| 组件 | 功能 |
|------|------|
| **SchemaForm** | 由 JSON Schema 自动渲染配置表单（类型/必填/枚举/依赖联动），零手写表单 |
| **TestRunner** | 沙盒试跑面板：填测试输入 → 调用 → 展示结构化结果/耗时/错误 |
| **AIAssistant** | 每个模块内嵌 AI 助手：`从描述生成 / 优化 / 改写 / 解释 / 翻译 / 审查` |
| **Importer** | 统一导入器：YAML / JSON / CSV / 文件拖拽 / Git 同步 / URL 拉取 / 市场(Store) |
| **Exporter** | 统一导出：当前版本 / 全部版本 / 打包迁移包 |
| **VersionHistory** | 版本列表 + diff 对比 + 一键回滚（版本即 git tag） |
| **StatusBadge** | 资源状态：草稿 / 测试中 / 已启用 / 已停用 / 异常 |

## 一、提示词管理（Prompt Manager）— 深度设计

> 用户点名场景：制作提示词要有管理界面 + AI 自动生成 + 外部导入。这是最核心的模块。

### 1.1 界面布局（详情页）

```
[配置] Tab（默认）
┌──────────────────────────────────────────────────────────┐
│ 基本信息：名称 / 类型(chat|few-shot|react|tool-use) / 标签   │
├──────────────────────────────────┬───────────────────────┤
│ 编辑器（左侧 70%）                │ 变量/区块面板（右侧 30%） │
│ ┌──────────────────────────────┐ │ ├ 变量列表 {role}{domain}│
│ │ 语法高亮 + 变量高亮           │ │ │   ↳ 自动从模板扫描       │
│ │ 区块折叠: system/user/assist  │ │ ├ 区块预算条（长度控制）  │
│ │ 实时 token 计数               │ │ ├ 引用外部资产：          │
│ │ 模板语法校验 ✅/❌             │ │ │  [记忆注入] [检索注入]  │
│ └──────────────────────────────┘ │ │  [工具结果] [示例库]    │
│ [💡 AI 生成▾] [📥 导入▾] [🧪 测试]│ │ └───────────────────────┘
└──────────────────────────────────┴───────────────────────┘
```

### 1.2 AI 自动生成（AIAssistant 子功能）

| 动作 | 输入 | 输出 | 说明 |
|------|------|------|------|
| **从描述生成** | "写一个资深法务顾问的 system prompt，要求引用法条" | 完整 prompt 草案 | 描述 → 结构化的 system+规则+约束 |
| **优化** | 现有 prompt | 优化版 + 改动说明 diff | 按 Anthropic 八原则/OpenAI 最佳实践 |
| **改写语气** | prompt + 目标语气 | 改写版 | 专业/口语/严厉/友好… |
| **多语言** | prompt + 目标语言 | 翻译版（保留变量） | `{变量}` 不被翻译 |
| **防注入审查** | prompt | 风险报告 | 检测指令冲突/越权指令/提示注入面 |
| **Few-shot 生成** | 任务描述 + 2-3 样例 | 补全 N 条示例 | 保持格式一致 |
| **版本对比解释** | v1 vs v2 | 变更摘要 | 为什么改了什么 |

生成结果默认**另存为新版本（草稿）**，永不直接覆盖线上版本。

### 1.3 外部导入（Importer）

| 通道 | 格式/来源 | 映射规则 |
|------|----------|---------|
| 文件 | YAML / JSON / MD / TXT | 自动识别结构；纯文本→单块 system |
| Git 同步 | 仓库 + 路径 | 订阅远端 prompt 目录，`git pull` 自动更新 |
| URL 拉取 | 提示词分享链接 | 抓取并结构化 |
| 市场（Store） | 内置模板市场 | 分类浏览 + 一键导入 + 自动适配变量 |
| 从其他平台 | OpenAI / Anthropic / Dify 导出 | 格式转换器（各平台 → 本平台 schema） |

### 1.4 控制与生命周期

- **草稿→测试→启用**：测试台选模型试跑（见 1.5），通过后启用，未启用不参与线上
- **版本管理**：每次保存=新版本（git commit），支持 diff/回滚/锁定（禁止修改）
- **A/B 测试**：同一 prompt 两个版本按流量比例分流，看效果指标
- **线上监控**：启用后自动接 L13 监控（每次调用的 prompt 版本/耗时/失败率）

### 1.5 测试台（TestRunner）

```
输入框：测试文本（可多组）        [运行]
输出：多模型对比（model A vs B）
指标：延迟 / token / 格式合规 / 失败重试次数
[通过 → 点击"启用此版本"]
```

## 二、模型管理（Model Manager）

### 2.1 布局

```
[配置]：Provider 列表卡片（OpenAI/Anthropic/Google/DeepSeek/本地 Ollama…）
  每个 Provider：
  ├ API 配置：base_url / api_key（加密存储，只显示 ****）/ 多 key 轮换池
  ├ 模型清单：模型名 / 上下文窗口 / 价格 / 能力徽章(工具/视觉/流式)
  ├ 默认参数：temperature / max_tokens / timeout / max_retries
  ├ Fallback 链：[主模型 → 备选1 → 备选2] 拖拽排序
  └ [连通性测试] 按钮 → 发 ping，显示延迟与报错
```

### 2.2 AI 生成 / 外部导入

- **AI 生成**：无（模型配置是事实数据，但可"自动推荐"：按任务类型建议模型+参数）
- **外部导入**：`provider 预设包`（社区整理的模型参数 json）、OpenAI 兼容端点一键粘贴（base_url+key 自动探测能力）

### 2.3 控制

- key 加密存储（M11），永不明文返回；权限：仅管理员可看/改 key
- 模型可用性健康检查（定时 ping + 状态徽章）
- 切换模型即时生效（热加载），当前会话可选模型

## 三、工具管理（Tool Manager）

> 已有 ToolRegistry（代码层），补管理界面。

### 3.1 布局

```
[配置] Tab：
├ 工具列表（分组：内置/自定义/MCP）：名称 / 描述 / Schema 摘要 / 状态 / 来源
├ 点击工具 →
│  ├ Schema 可视化：参数表（必填/类型/枚举/默认值）由 JSON Schema 渲染
│  ├ 权限：谁可用（角色白名单）/ 危险等级（只读|写|执行 shell）
│  ├ 参数默认值 & 安全限制（超时/输出截断/路径白名单）
│  └ [🧪 试跑]：填参数 → 执行 → 展示结果 + 耗时 + 审计记录
├ MCP 管理：连接列表（stdio/HTTP/SSE）→ [新增连接] 向导：
│   选传输 → 填命令或 URL → 探测 tools → 勾选导入 → 确认
└ 工具热加载：拖拽 .py/.js 插件文件 → 自动注册（M4.21）
```

### 3.2 AI 生成 / 外部导入

- **AI 生成**：输入"我想让 agent 能查询公司销售数据" → 生成工具描述+参数 Schema 骨架 → 人工补实现代码
- **外部导入**：MCP 市场（smithery 等）浏览安装、OpenAPI 文件导入（swagger→工具）、Python 函数文件上传（自动解析签名生成 Schema）

### 3.3 控制

- 启用/停用即时生效；危险工具二次确认弹窗
- 每次调用进审计日志（M4.20），界面可查"谁在何时调了啥"
- 工具冲突检测（同名/同 schema 冲突告警）

## 四、Agent 管理（Agent Manager）

### 4.1 布局

```
[配置]：
├ Agent 列表：类型模板（chat/coding/planner…）+ 自定义
├ 基本信息：名称/头像/描述/系统提示（链接到 Prompt 资产）
├ 运行时：框架（framework 选型）/ 模型（链接到模型资产）/ 温度 / max_steps
├ 工具集：勾选启用（链接工具资产）/ 记忆策略（链接记忆资产）
├ 编排：graph_type（single/supervisor/react）+ 子 Agent 列表（拖拽编排）
└ Graph 可视化：节点-边图（LangGraph 风格），点击节点看配置
[测试]：对话试跑 / 批量测试 / 对比不同配置
[运行]：在线会话列表、手动停止/恢复、资源占用
```

### 4.2 AI 生成 / 外部导入

- **AI 生成**：输入"帮我做一个能写周报的 agent" → 生成 agent.yaml 完整配置（含系统提示/工具集/记忆策略）→ 预览 → 保存为草稿
- **外部导入**：`agent.yaml` 文件导入（本平台格式）、从其他平台（Dify/Coze 导出）转换、模板市场一键复制

### 4.3 控制

- 配置 → 测试 → 发布（发布后生成新版本，线上流量自动切换或灰度）
- 每个 Agent 独立 API key 权限、独立审计、独立监控面板

## 五、记忆与知识库管理（Memory & Knowledge Manager）

### 5.1 布局

```
[配置]：
├ 记忆策略：类型（buffer/summary/rag/hybrid）+ 参数（窗口大小/摘要阈值/向量库）
├ 知识库列表：名称 / 文档数 / 分块数 / 向量库状态
├ 知识库详情：
│  ├ 文档管理：上传（pdf/md/docx/csv/网页 URL）/ 删除 / 重新解析
│  ├ 分块参数：chunk_size / overlap / 分隔策略（预览分块结果）
│  ├ 嵌入模型：选择 embedding provider
│  └ [🔍 检索测试]：输入 query → 展示 Top-K 召回结果 + 相似度分数 + 命中片段高亮
[运行]：索引任务队列、失败重试、增量同步
```

### 5.2 AI 生成 / 外部导入

- **AI 生成**：上传文档后"自动分块+自动生成摘要/元数据标签/FAQ"，提升检索质量
- **外部导入**：文件批量拖拽、Notion/Confluence 连接器、向量库直接对接（Chroma/PGVector/Milvus 填连接串）

### 5.3 控制

- 检索质量评估：内置黄金问题集，跑召回率指标
- 版本：文档更新自动生成索引版本，可回滚旧索引
- 权限：知识库级访问控制（哪些 Agent 可用）

## 六、编排管理（Orchestration Manager）

### 6.1 布局

```
[配置]：
├ 编排模式：single / supervisor / swarm(handoff) / group-chat
├ 子 Agent 拓扑图（拖拽连线）：supervisor → [agent A, agent B] → aggregator
├ 每条连线的路由规则（关键词/LLM 路由/固定）
├ A2A 远端注册表：远端 Agent 列表（agent card 导入）/ 连接状态 / 超时 / 认证
└ 任务参数：max_subtasks / timeout / 并发上限
[运行]：任务监控面板——实时任务 DAG、每节点状态（排队/执行/完成/失败）、耗时瀑布
```

### 6.2 AI 生成 / 外部导入

- **AI 生成**："这个任务适合几个 agent 分工？" → 生成编排拓扑 + 每个子 agent 职责
- **外部导入**：A2A Agent Card URL 一键注册远端 agent；编排配置 yaml 导入

### 6.3 控制

- 节点级暂停/恢复/重试（HITL 界面化）
- 失败节点自动重试策略（次数/退避），超过阈值告警
- 全链路 trace 与监控联动（L13）

## 七、评估管理（Evaluation Manager）

### 7.1 布局

```
[配置]：
├ 数据集管理：列表（名称/条数/标签）→ 详情（用例表格：输入/期望输出/评分标准）
│   ├ 新增用例（手动 / AI 生成 / 导入 csv-json）
│   └ 标注界面：人工标注 / LLM-as-judge 预标注后人工确认
├ 评测运行：选数据集 + 选 Agent 版本 → 跑分 → 结果报告
├ 报告视图：总分 / 分项 / 通过率 / 失败用例详情（输入-实际输出-期望-错误原因）
└ 回归对比：v1 vs v2 版本分数 diff，防止优化 A 弄坏 B
```

### 7.2 AI 生成 / 外部导入

- **AI 生成**：从需求描述生成测试用例集（覆盖边界/对抗/正常路径）；失败用例自动分类归因
- **外部导入**：`eval/sample_tasks.json`（✅ 已有）、csv、标注平台导出（LabelStudio 等）

### 7.3 控制

- 评测通过阈值配置：pass_rate < X 自动阻止发布（质量门禁，接入 CI）
- 报告可导出 PDF/Markdown，供团队评审

## 八、监控与告警管理（Observability Manager）

### 8.1 布局

```
[配置]：
├ 指标看板：请求量 / 延迟分位 / token 消耗 / 工具失败率 / 成本估算（图表组件）
├ 追踪（Trace）：按 trace_id 查全链路瀑布（prompt→模型→工具→记忆→回复）
├ 日志查看器：结构化日志搜索（level/service/error 过滤）
├ 告警规则：指标 + 阈值 + 持续时间 → 通知渠道（邮件/钉钉/飞书/webhook）
│   例：tool 失败率 > 10% 持续 5min → 钉钉告警
└ 数据漂移检测：输入分布对比（训练 vs 线上）→ 漂移预警
```

### 8.2 AI 生成 / 外部导入

- **AI 生成**：异常日志自动摘要归因（"这次 P0 是因为 xxx"）；告警规则模板推荐
- **外部导入**：Grafana 仪表盘 JSON 导入、OTel 数据接入

### 8.3 控制

- 告警静默/升级策略（P0 电话 → P1 群消息 → P2 邮件）
- 指标保留策略与存储成本控制

## 十二、对 feature-checklist 的影响

| 变更 | 内容 |
|------|------|
| M8.16 | 管理控制台骨架（资源列表/4-Tab 详情/权限分层） |
| M8.17 | 提示词管理界面（编辑器+变量+版本+测试台） |
| M8.18 | AI 自动生成能力（每个资源模块内嵌 AIAssistant：生成/优化/改写/审查） |
| M8.19 | 外部导入导出（文件/Git/URL/市场/平台转换） |
