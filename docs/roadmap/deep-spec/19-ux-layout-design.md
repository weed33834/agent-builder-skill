# 19. 布局与设计规范（Layout & Design System）

> **定位**：用户原话——"布局，设计，记得顺便提一下这些东西，因为他如果不提的话，很多东西挤在一起，根本不知道怎么分类跟怎么分"。本份解决**信息怎么组织、页面怎么分区、东西怎么分类**：信息架构 → 页面布局模式 → 导航系统 → 内容组织方式 → 设计系统 → 关键页面布局规格。7 域 ≈70 项。
> **对照基准**：Dify/Coze 管理后台（顶部一级导航+左侧二级导航+主内容区）、Open WebUI、LobeChat、AntD/Element 后台布局、vue-element-admin 三大布局模式。
> **核心原则**：①一个资源一个页面，一个页面一个主任务；②分类靠导航+Tab+筛选三重结构，永不把全部功能堆一屏；③所有页面遵守同一骨架（Header/侧边栏/内容区），用户换页面不迷路。

## A. 信息架构（12 项）

| # | 项 | 规格 |
|---|----|------|
| A.1 | 顶层分类原则 | 按**对象类型**分一级模块（对话/智能体/工作流/模型/工具/知识库/任务/监控/审计/设置），不按功能动作分（"管理""配置"不作为一级分类） |
| A.2 | 对象→页面映射 | 每个资源类型 = 一个列表页 + 一个详情页 + 一个创建页；禁止一个页面堆 5 类资源 |
| A.3 | 一级导航清单（本项目） | 工作台 Dashboard / 对话 Chat / 智能体 Agents / 工作流 Workflows / 模型 Models / 工具与 MCP Tools / 知识库 Knowledge / 记忆 Memory / 任务 Tasks / 监控监控 Monitor / 审计 Audit / 系统设置 Settings（12 个一级模块，M0-M14 全落位） |
| A.4 | 二级导航（模块内） | 列表 / 分类 Tab / 详情子页（配置-测试-运行-审计 4-Tab 统一模式） |
| A.5 | 命名规范 | 名称=动词或名词短语、≤8 字、全局唯一；同一对象在所有页面用同一名称（禁止"智能体/Agent/Bot"混用） |
| A.6 | 层级深度 | 导航层级 ≤3 级（一级导航→二级 Tab→页内分区）；超过 3 级必须用面包屑+搜索兜底 |
| A.7 | 状态分类 | 所有资源列表页必须有状态 Tab（全部/已发布/未发布 或 全部/运行中/已停用）——参考 Dify 智能体页 |
| A.8 | 资源归属 | 资源带归属标识（个人/团队/组织/系统），列表页可按归属过滤（16-A 联动） |
| A.9 | 信息密度分级 | 列表页看全量、卡片页看重点、详情页看细节；同一数据三档展示，不互相替代 |
| A.10 | 搜索兜底 | 所有列表页顶部有全局搜索（关键词/标签/创建人），超 50 项必须支持筛选（状态/类型/时间/归属） |
| A.11 | 入口一致性 | 同一操作只有 1 个主入口 + 1 个快捷入口（如"新建智能体"= 列表页右上角按钮 + 全局命令面板，不许第三处） |
| A.12 | 空状态设计 | 每个列表页有空状态：图标+说明+引导创建按钮+示例链接（"还没有智能体，点击创建第一个"） |

## B. 页面布局模式（12 项）

| # | 模式 | 适用 | 规格 |
|---|------|------|------|
| B.1 | 后台标准骨架（左右框架） | 管理台所有页面 | 顶部 Header（Logo+一级导航+搜索+用户区）+ 左侧 Sidebar（二级导航）+ 主内容区；内容区宽度 ≥960px |
| B.2 | T 型布局 | 仪表盘/门户首页 | Header 横贯 + 下方多栏内容区（卡片网格） |
| B.3 | 对话页布局（双栏） | 对话/Chat | 左侧会话列表（260-320px，可折叠）+ 右侧对话主区（消息流+输入区）；参考 ChatGPT/Coze |
| B.4 | 详情页布局（左配置右测试） | 智能体/工作流/模型详情 | 左侧设置执行区（角色设定/回复逻辑/开场白/追问规则），右侧测试区（实时预览对话）——参考 Dify 详情页 |
| B.5 | 工作流画布布局 | 工作流编辑 | 左侧节点工具栏（可搜索、一键添加）+ 中央画布（拖拽连线）+ 右侧属性面板；画布可缩放平移 |
| B.6 | 知识库布局 | 知识库管理 | 左侧文档树/分类 + 右侧文档列表与预览 + 底部检索测试区 |
| B.7 | 资源列表页布局 | 所有资源列表 | 顶部状态 Tab + 筛选栏 + 右侧操作区；主体为列表/卡片网格；底部或顶部右侧分页 |
| B.8 | 三栏工作台 | Dashboard | 左栏（任务/待办）、中栏（核心指标与图表）、右栏（动态/通知/快捷入口）——参考 OA 工作台 |
| B.9 | 向导式布局（分步） | 创建流程 | 3-5 步分步向导（基础信息→能力配置→测试→发布），步进器显示进度，最后一步可回跳 |
| B.10 | 抽屉+弹窗 | 轻量操作 | 编辑 5 字段内用抽屉/弹窗；超过 5 字段必须进详情页（A.2） |
| B.11 | 全屏模式 | 画布/测试/审计大屏 | 工作流编辑、对话测试、监控大屏支持全屏沉浸 |
| B.12 | 布局一致性 | 全局 | 所有页面 Header/Sidebar 固定不随路由变化；内容区统一 24px 栅格间距；页面间切换不跳骨架 |

## C. 导航系统（10 项）

| # | 项 | 规格 |
|---|----|------|
| C.1 | 一级导航 | 顶部或左侧固定；当前项高亮；带图标+文字（≥3 字避免纯图标歧义） |
| C.2 | 二级导航 | 左侧 Sidebar 跟随一级模块切换；可折叠（收起为 64px 图标栏） |
| C.3 | 面包屑 | 详情页必显示（一级 > 二级 > 当前对象），可点击回跳 |
| C.4 | Tab 内切换 | 详情页 4-Tab（配置-测试-运行-审计）在同一页内切换，不刷新不丢状态 |
| C.5 | 快捷入口 | Dashboard 放高频入口卡片（新建对话/新建智能体/新建工作流/上传知识） |
| C.6 | 全局命令面板 | Ctrl+K 唤起命令面板：搜索资源/跳转页面/执行操作/创建（参考 15-ux 高级交互域） |
| C.7 | 最近使用 | 导航底部显示最近访问资源（最近对话/最近编辑的智能体），默认 5 条 |
| C.8 | 收藏/置顶 | 资源支持收藏，收藏夹显示在导航顶部 |
| C.9 | 通知入口 | Header 右侧铃铛图标+未读角标；点击弹出通知面板（15-ux 通知域） |
| C.10 | 用户区 | Header 最右：头像+下拉（个人信息/主题切换/偏好设置/退出登录） |

## D. 内容组织与分类展示（12 项）

| # | 项 | 规格 |
|---|----|------|
| D.1 | 列表 vs 卡片 vs 表格 | 信息少用卡片（智能体/应用）、信息多用表格（模型/工具/任务/审计）、简单清单用列表；同页不混用三种 |
| D.2 | 卡片设计 | 卡片=缩略图/图标+名称+一句描述+状态徽标+操作（hover 出现）；网格 4 列自适应 |
| D.3 | 表格设计 | 首列=名称（可点击进详情）、状态列带色点、操作列右侧固定；支持列排序、列隐藏 |
| D.4 | 状态徽标体系 | 统一色规：运行中=绿、已停用=灰、错误/失败=红、草稿=黄、审核中=蓝；全局一致不得换色 |
| D.5 | 标签分类 | 资源支持多标签；标签可筛选、可批量打标；系统标签（官方）与用户标签视觉区分 |
| D.6 | 分组展示 | 列表支持分组视图（按类型/按归属/按标签/按时间）；分组头可折叠 |
| D.7 | 时间线 | 审计日志/运行记录/版本历史用时间线展示（时间轴+类型图标+摘要） |
| D.8 | 树形结构 | 知识库文档树/组织架构/技能分类用树形；树支持搜索定位 |
| D.9 | 看板（Kanban） | 任务管理支持看板视图（待办/进行中/已完成），可拖拽流转 |
| D.10 | 图表规范 | 指标卡（数字+趋势）+ 折线（时间序列）+ 柱状（对比）+ 环形（占比）；一屏图表 ≤4 个 |
| D.11 | 筛选器组合 | 状态+类型+归属+时间+关键词 可组合筛选；筛选结果 URL 可分享/保存为视图 |
| D.12 | 排序与分页 | 默认按更新时间倒序；支持按名称/创建时间/状态排序；分页 20/50/100 可选 |

## E. 设计系统（10 项）

| # | 项 | 规格 |
|---|----|------|
| E.1 | 色彩体系 | 主色 1 个（品牌色）+ 功能色（成功/警告/错误/信息）+ 中性色 8 档；使用 60-30-10 比例 |
| E.2 | 字体 | 中文默认系统字体栈（PingFang/Microsoft YaHei/Noto Sans SC）；正文 14px、标题 16/20/24px；等宽字体用于代码/日志 |
| E.3 | 间距栅格 | 8px 基数（8/16/24/32）；卡片内边距 16px；页面外边距 24px |
| E.4 | 圆角与阴影 | 卡片圆角 8px、按钮 6px；阴影 3 级（hover 1 级/浮层 2 级/弹窗 3 级） |
| E.5 | 图标 | 统一图标库（AntD Icons/Lucide），线性风格；语义图标不得混用 |
| E.6 | 组件库 | 统一 AntD/Element 定制主题，禁止裸写私有组件；缺失组件先扩展组件库 |
| E.7 | 暗色模式 | 明暗双主题；CSS 变量驱动，一键切换；图表随主题联动 |
| E.8 | 动效 | 过渡 200-300ms 缓动；禁止无意义弹跳动画；流式输出打字机效果除外（见 20-A） |
| E.9 | 品牌一致性 | Logo/品牌色/水印统一；对外发布页与管理台同设计语言 |
| E.10 | 设计令牌（Design Token） | 颜色/字体/间距/圆角全部抽为 token（CSS 变量+TS 常量），禁止硬编码 |

## F. 响应式与无障碍（8 项）

| # | 项 | 规格 |
|---|----|------|
| F.1 | 断点 | ≥1440（大屏 4 列）/ 1200（3 列）/ 992（2 列）/ ≤768（移动端单列+抽屉导航） |
| F.2 | 移动端适配 | 管理台核心查看功能移动可用；对话页全功能移动可用；复杂编辑器提示用桌面 |
| F.3 | 键盘可达 | 全功能键盘可达（Tab 顺序合理、Enter 提交、Esc 关闭弹窗） |
| F.4 | 对比度 | 正文与背景对比度 ≥4.5:1；状态色不单独作为信息唯一表达（配文字） |
| F.5 | 焦点可见 | 键盘焦点环明显（2px 主色描边），不得隐藏 |
| F.6 | 缩放 | 页面在 200% 缩放下无内容截断；禁止固定像素宽度布局 |
| F.7 | 文案可读 | 错误提示用人类语言（见 21-B）；长列表加载态用骨架屏 |
| F.8 | 减少动效偏好 | 尊重 prefers-reduced-motion，关闭非必要动效 |

## 布局自检清单（发布前过一遍）

1. 每个一级模块是否有独立页面，是否遵循标准骨架（B.1）？
2. 列表页是否有状态 Tab + 筛选 + 搜索 + 空状态（A.7/A.10/A.12）？
3. 详情页是否为"左配置右测试"4-Tab 结构（B.4）？
4. 所有命名是否与全局词典一致（A.5）？
5. 是否有超过 3 级的导航（A.6）？
6. 同一操作是否只有 ≤2 个入口（A.11）？
7. 颜色是否只用设计 token、状态色是否统一（E.10/D.4）？
8. 键盘与对比度是否达标（F.3/F.4）？
9. 移动端/暗色模式是否可用（F.1/F.2/E.7）？
