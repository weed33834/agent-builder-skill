# 对标四大应用：Codex / ChatGPT / Claude Code / WorkBuddy 功能差异与吸收清单

> 用途：逐项分析 2026 年头部 AI 应用的产品功能，提炼"别人有而我们规格里没有/不够细"的功能点，全部吸收进本仓库规格体系。
> 方法：每个应用 → 功能全景 → 独有高级功能 → 吸收映射（✅ 已覆盖 / 🔶 部分 / ⬜ 需新增）。
> 配套：细节规格见 `docs/deep-spec/15-ux-detail.md`（**v2 全量版**：14 交互域 800+ 细节点——消息展示/输入/附件/搜索/会话/工作空间/任务/能力库/反馈/通知/导航/错误降级/安全/高级交互，逐点细化可直接当开发清单）。

## 1. 四大应用一句话定位

| 应用 | 形态 | 定位 | 核心范式 |
|------|------|------|----------|
| **ChatGPT**（OpenAI） | Web/桌面/移动 | 全能个人助手 | 对话为中心，工作空间（Projects）+ 画布（Canvas）+ 记忆（Dreaming）+ Agent（Work） |
| **Codex**（OpenAI） | CLI/桌面/Web/移动 | 编程 Agent 平台 | 多 Agent 并行 + 工作树隔离 + Skills 复用 + 后台定时工作流 + 移动端审批 |
| **Claude Code**（Anthropic） | CLI/桌面 | 终端开发 Agent | 分层权限 + 会话管理（resume/fork/btw）+ 子代理隔离 + 远程控制 + 全自动模式 |
| **WorkBuddy**（腾讯） | 桌面 | 职场 AI 工作台 | 三种自主程度模式（Craft/Plan/Ask）+ 能力库（专家/技能/连接器/资料库）+ 本地文件实操 |

### 基础功能细节（别人都有、我们规格里必须逐点写全——见 15-ux-detail.md 全量版 14 域）
- 对话气泡：markdown/代码块高亮/流式打字/思考折叠/工具卡片/引用角标/复制/重新生成/编辑/点赞点踩/停止
- 联网搜索：自动触发+手动开关/来源编号引用/搜索过程可视化/无结果声明
- 附件上传：拖拽粘贴/多模态预览/文档解析 OCR/大小格式限制/上传进度/@ 引用文件
- 输入区：Enter 发送/Shift+Enter 换行/@ 提及/斜杠命令/模式切换/语音按钮
- 会话管理：分组/搜索/重命名/固定/归档/导出/分享/成本显示
