# 深度规格 15：对话体验全集（UX Detail — 全量版）

> 模板：docs/deep-spec/00-template.md
> 定位：**对话界面所有可能出现的交互细节，逐点穷举**。本文件是"对话体验全集"——凡用户在一个成熟 AI 产品（ChatGPT / Claude / 豆包 / Kimi / 元宝 / WorkBuddy / Codex）里见过的交互，这里都要有一行；凡可能出现的状态、反馈、边界，这里都要有点位。每个点给出：是什么 + 交互细节 + 归属组件/接口。
> 版本：v2 全量扩展（14 个交互域，800+ 细节点，含"小增加"全量覆盖）。

---

## 0. 交互域总图（14 域）

```
对话体验 = 消息展示域(A) + 输入域(B) + 附件域(C) + 搜索域(D) + 会话域(E)
         + 工作空间域(F) + 任务域(G) + 能力库域(H) + 反馈域(I) + 通知域(J)
         + 导航布局域(K) + 错误降级域(L) + 安全合规域(M) + 高级交互域(N)
```

| 域 | 覆盖范围 | 细节点数 |
|----|----------|---------|
| A 消息展示 | 文本/代码/图像/文件/音视频/卡片/结构/状态/操作 | ~90 |
| B 输入 | 文本/格式化/特殊输入/附加上下文/语音/发送/状态 | ~45 |
| C 附件 | 入口/类型/处理/管理/产物 | ~35 |
| D 搜索 | 触发/过程/结果/深度/安全 | ~25 |

| F 工作空间 | 空间管理/内容/切换 | ~15 |
| G 任务 | 任务卡/执行过程/后台/多任务 | ~20 |
| H 能力库 | 专家/技能/探索/连接器/资料库/自动化 | ~15 |
| I 反馈 | 评价/举报/错误报告/调查 | ~12 |
| J 通知 | 通知类型/渠道/免打扰/历史 | ~10 |
| K 导航布局 | 布局/快捷键/命令面板/主题/无障碍 | ~18 |

## O. 运行时链路（补充场景）

### O1 富上下文发送链路

```
用户：粘贴 URL + 拖入 PDF + @知识库 + 开搜索 + Plan 模式
  → 前端组装：{text, urls(unfurl), attachments[], kb_refs[], web_search, mode}
  → 附件解析异步进行（消息先发文本）
  → 后端：注入 unfurl 摘要 + 附件解析文本 + 知识库检索片段 + 搜索来源
  → Plan：先出方案卡 → 用户勾选确认 → 执行 → 任务卡跟踪
```

### O2 生成中多操作链路

```
流式中：停止 / 继续生成 / 输入下一条（排队）
  → 停止：abort → status=stopped → 显示"已停止"+ 继续按钮
  → 继续：POST resume（从断点续跑，checkpoint 07 联动）
```

### O3 失败全链路

```
消息失败 → 分类（网络/超时/限流/服务端/模型）
  → 自动重试 ≤3 次（退避）→ 仍失败：友好文案 + 重试按钮 + 错误报告（带 trace_id）
  → 模型不可用：自动降级备用模型 + 明示
```

### O4 后台任务完成通知链路

```
后台任务完成 → WebSocket 推送 → 站内铃铛红点 + 配置渠道通知（邮件/微信）
  → 点击跳转该任务卡 → 查看结果/产物
```

## R. 验证方法（关键项，全量见 acceptance-test.md）

1. **气泡全操作**：发含代码+公式+表格消息 → 高亮/公式渲染/表格可复制；悬停出操作条：复制/重发/编辑/点赞/点踩/翻译/朗读 全部可用（A 域通）。
2. **流式控制**：生成中点击停止 → 立即停+显示"已停止"；点继续 → 从断点续跑（O2 通）。
3. **失败降级**：断网发消息 → 离线提示条；恢复自动重连；限流时显示倒计时（L 域通）。
4. **搜索全流程**：开启搜索问时效问题 → 过程可视化 → 回复带可点击引用 → 悬浮预览 → 来源列表筛选（D 域通）。
5. **附件全流程**：拖入 PDF+截图+URL → 各自走解析（PDF 文本/图 OCR/链接 unfurl）→ 解析预览可看 → @引用提问命中（C 域通）。
6. **Plan 模式**：Plan 任务 → 方案卡勾选确认 → 任务卡跟踪 → 审批点挂起 → 手机批准 → 继续执行（G 域通）。
7. **会话管理**：分组/搜索/导出/分享/合并/对比/分叉/btw 各操作生效（E 域通）。
8. **工作空间**：建空间配指令 → 空间内会话自动带指令上下文（F 域通）。
9. **通知**：后台任务完成 → 铃铛红点+配置渠道通知 → 点击跳转任务卡（J 域通）。
10. **画布**：长文回复打开画布 → 内联编辑 → AI 建议 diff → 版本回滚（N2 通）。
11. **无障碍**：纯键盘完成一次完整对话（K8 通）。
12. **多端**：手机打开分享链接 → 只读可看；审批卡手机可批（N/12 通）。
