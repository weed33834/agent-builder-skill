# 全量验收测试清单（Acceptance Test Checklist）

> 用途：把 15 份深度规格的"验证方法"汇编为**可逐条执行**的验收清单。每一条= 操作步骤 + 预期结果。
> 用法：按模块逐条跑，✅ 通过 / ❌ 失败（失败记入 12-monitor 或提 bug）。
> 来源：docs/deep-spec/01-15 各文档第 7 章。

---

## 01 提示词系统（prompt-system）

| # | 步骤 | 预期结果 |
|---|------|----------|
| 01-1 | 新建提示词 → 填内容+变量 → 保存 | 提示词入库，版本 v1 |
| 01-2 | 修改并保存 → 查看版本列表 | 出现 v2，两版本可 diff |
| 01-3 | 引用变量 {input} 测试渲染 | 渲染正确，缺失变量有明确报错 |
| 01-4 | 导出提示词 → 在另一环境导入 | 配置完整还原 |
| 01-5 | 在对话中切换提示词版本 | 新消息用新版本，历史消息不受影响 |
| 01-6 | 含敏感占位符的提示词 → 检查日志 | 日志中占位符被脱敏（不泄露真实值） |
| 01-7 | 触发供应链检查（外部导入提示词） | 风险提示出现（提示注入/恶意指令扫描） |
